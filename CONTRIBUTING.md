# Contributing to Meye

Thank you for your interest in contributing to Meye!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature-name`).
3. Make your changes and test them thoroughly.
4. Commit your changes with a descriptive message.
5. Push your branch and submit a Pull Request.

## Development Environment Setup

Please refer to the [README.md](README.md) for instructions on setting up your local environment for web, macOS, and Android development.

## Bug Reports and Feature Requests

If you encounter any issues or have ideas for new features, please open an issue on the GitHub repository with detailed information.

## Code Style

- We use standard modern JavaScript/ES6.
- Keep the UI responsive and maintain the current minimalist aesthetic.
- Avoid introducing heavy dependencies unless absolutely necessary.
